# SwiftDrop 🟢

**Hyderabad's own parcel delivery startup** — anything, anywhere in the city, in minutes.

> "The price you see is the price you pay — no surge, ever."

## Vision
Start parcel-only (like Rapido Parcel) in Kukatpally / KPHB, Hyderabad. Open booking for anyone.
Riders keep ~95% of every delivery (platform takes 5–8%). Passenger rides come later.

## Fare model
- **Base:** ₹30 for the first 3 km
- **Per km after that:** ₹10/km
- Example: 5 km trip = ₹30 + (2 × ₹10) = **₹50**

## Launch plan
1. **Phase 0 — WhatsApp MVP:** manual dispatch in Kukatpally, 20–50 orders/day
2. **Phase 1 — App launch:** Kukatpally + KPHB zone, 15–25 riders
3. **Phase 2 — Expand:** zone-by-zone across Hyderabad, then passenger rides
